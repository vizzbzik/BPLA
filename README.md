# BPLA
Итоговая аттестация в симуляторе
Инструкция по установке:
Установите симулятор Uncrashed, зайдите по ссылке https://steamcommunity.com/sharedfiles/filedetails/?id=3840196520 и подпишитесь на карту. Она появится в симуляторе, зайдите в одиночный полет и найдите данную карту. Экзамен оценивает специалист.
